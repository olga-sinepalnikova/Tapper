# Tapper

## What is it?
It's a small pet project in which I solve big system-design problems that I could not meet in my day-to-day job. The idea of a project is simple - you tap to earn coins, you spend coins to chat with anybody.

Important note: All backend is practically AI-free, I will probably use AI to finalize some of my decisions, discuss ideas and review. But all frontend will be AI-first since I don't really know how to do frontend.
